# Personal-AI — Personal AI OS

> 长期存在的 Brain：Memory + Identity + Reflection + Goal + Planning

## 项目定位

Personal-AI 不是另一个 AI Agent。Personal-AI 的目标是成为**长期存在的 Personal AI OS**——一个以 Brain 为核心的系统。

与 AI Agent 的根本区别：
- **Agent** 是任务驱动的、无状态的、可替换的执行单元
- **Personal-AI** 是身份驱动的、有状态的、持续演化的 Brain

## 五大核心能力

| 能力 | 定义 |
|------|------|
| Memory | 跨会话、跨时间、跨场景的持久化记忆 |
| Identity | 稳定且可演化的身份认同 |
| Reflection | 对自身行为、决策、记忆的元认知能力 |
| Goal | 长期目标的设定、追踪、分解、调整 |
| Planning | 基于目标生成执行计划、资源调度、动态重规划 |
